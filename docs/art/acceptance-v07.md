## Actual client and dedicated-server results

Used the built release JAR in both `build/visual-v07/client/mods` and
`build/visual-v07/server/mods`, with no testmod. The isolated world was copied
from the previous disposable gallery; the original run was retained.

| Check | Actual result |
| --- | --- |
| Dedicated server | Common startup and Done marker; world save/stop/restart succeeded; test runs shut down normally |
| Production client | Joined the dedicated server with the built JAR; client startup completed |
| Full blocks | V06 foregrounds visible; Router sides/top and underside sampled; Provider six orientations displayed; Endpoint retained EAST functional face |
| Bridge | Native AE2 multipart appearance in all six exhibit mountings and next to a real AE2 cable host |
| Cable | All 64 real-neighbor masks displayed, including isolated, end, three axes, turns, branches and six-way intersection |
| Isolated transitions | Adding an adjacent real cable changed the node to a connected segment; removing it restored the closed layered node |
| Placement | Actual XTEST mouse right-click placed a cable at 9,1,4; server execute-if-block confirmed V07_PLAYER_PLACEMENT_CONFIRMED |
| Items | All five inventory icons and hand models captured; dropped entities visible in gallery |
| Lighting/animation | Noon and midnight captures; successive night frames show animated interiors with stationary rings |
| Resource reload | F3+T completed with the same assets and no missing model/texture errors |
| World reload | Save-all, complete server/client shutdown, dedicated restart and client rejoin completed; saved gallery rendered again |

One initial automatic client connection happened before the first server was
ready and was refused. The client was restarted after readiness; this startup
race is not counted as a successful join. Subsequent joins passed. No Mod change
was needed. Existing vanilla/LDLib2 shader warnings and optional Ponder integration
warning remain; no AE2 Federation asset-loading errors were found. Server startup
also reported a roughly five-second catch-up warning on this shared host; its
cause was not isolated and is not claimed as a business performance result.

## Rendering sample

Xvfb, 1280x720, software OpenGL, render distance 8, max FPS 60. Vanilla F3+L,
about ten seconds per stationary view. The existing scene contains 2,048 ordinary
connected cables plus 128 machines; it is not a throughput factory benchmark.

| Scene | Frames | Mean frame time | P95 | Max queued uploads / batches |
| --- | ---: | ---: | ---: | ---: |
| Gallery | 563 | 17.67 ms | 20.22 ms | 0 / 0 |
| 2,048 cables + 128 devices | 201 | 49.76 ms | 53.14 ms | 0 / 0 |

The unchanged baked-model wrapper selects one of 64 cached models during chunk
rebuilding. No new per-frame geometry, particles, synchronization or dynamic
world lighting was added. The isolated state adds a glass layer and animated
core compared with its old solid cube; this has real rendering cost. These
samples show no persistent model-build/upload queue in the tested views, not
zero rendering cost or a hardware-GPU performance guarantee.

The first pair of night captures landed on an indistinguishable animation phase
and was not used as motion evidence. A supplemental six-frame native F2 burst
confirmed changes in the cable-only region; the night image pair now uses two
distinct frames from that burst.

## Limits

No hardware GPU, Fabulous mode, shader pack or third-party renderer compatibility
pass was run. No exhaustive transparent sorting check from every camera or long
session is claimed. Bridge shape/Part rotation and Provider rotation code did
not change; all six exhibit states were viewed, but a new exhaustive mouse-based
wrench cycle and selection-edge comparison were not repeated in this pass.
No unrelated factory/crafting/permission stress qualification was rerun.

Repeatable scene creation, server/client launch and screenshot commands are in
[README.md](README.md). The scene script clears a bounded area and should only
be used in a disposable test world. All test processes were stopped after the
final save; the world and evidence remain available for repeat review.
