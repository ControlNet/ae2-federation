# Nexus idea archival (2026-10-09)

Archived [the Nexus discussion](../../docs/archive/ideas/nexus-processor.md) after inspecting the current item
registrations, three recipe JSON files, device recipe references, language entries, icons/models, and English
GuideME acquisition page. The current implementation follows the 2026-10-08 revision:

- Logic Press + Ender Pearl -> Printed Nexus Circuit, retaining the press.
- Printed Nexus Circuit + Redstone Dust + Printed Silicon -> Nexus Processor, consuming all three inputs.
- Fluix Crystal + Ender Dust + Nexus Processor -> sixteen Nexus Cores in a shaped row.
- Cable, Bridge, Router, Pattern Provider, and Processing Endpoint recipes use the core.

The old core-to-processor proposal and its no-new-circuit restriction remain historical, explicitly superseded.
Moved the idea to the implemented index, linked the existing
[survival feature document](../../docs/features/survival-playability.md), and repaired archive and knowledge links.
This was a documentation archival pass, not a runtime acceptance run; no game tests were rerun.
