# Creative ME Federation Computing Device

<BlockImage id="ae2federation:creative_computing_device" scale="6" />

Runs Federation programs for its domain, with no limit on [compute or bandwidth](../automation/compute.md). It is
meant for testing; in survival, the Federation computation system built on Neo ECO's computation structure runs
programs.

* **All six faces:** take <ItemLink id="ae2federation:cable" /> only. The device joins the domain through them and
  counts 1 toward the cable's [capacity](../mechanics/capacity.md), like an Endpoint. It uses no power.
* **Programs** installed on it act through the domain's
  <ItemLink id="ae2federation:automation_interface" />s. Install them in the Federation screen's Automation tab
  ([Installing and Triggers](../automation/installing.md)).
* **Redstone:** a signal arriving at the device starts the programs set to start on redstone.
* **ID and alias:** every device has an ID, such as `device-k3m9qa`, that stays until it is broken. Right-click
  it to see or copy the ID, or to give the device an alias. An alias must be unique among the domain's devices and
  must not look like an ID.

It is only available in creative mode.
