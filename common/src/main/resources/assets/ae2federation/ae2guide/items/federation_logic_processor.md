# Federation Logic Processor

<ItemImage id="ae2federation:federation_logic_processor" scale="4" />

The ingredient in every Federation device. Press it in an <ItemLink id="ae2:inscriber" />: Fluix Dust in the top
slot, a <ItemLink id="ae2:logic_processor" /> in the middle, and the bottom slot empty. Both inputs are used up.
The recipe also works with the dust in the bottom slot.

<RecipeFor id="ae2federation:federation_logic_processor" />

It can be automated like AE2's own processors: an Inscriber fed from one side puts the
<ItemLink id="ae2:fluix_dust" /> in the top slot and the processor in the middle by itself.

Used in: <ItemLink id="ae2federation:bridge" />, <ItemLink id="ae2federation:cable" />,
<ItemLink id="ae2federation:pattern_provider" /> and <ItemLink id="ae2federation:processing_endpoint" />.
