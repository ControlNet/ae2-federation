# ME Federation Router

<BlockImage id="ae2federation:router" scale="6" />

The Router is not fully implemented yet and has no use for now. <ItemLink id="ae2federation:cable" /> already
connects and branches on its own, so you do not need a Router to build a
[Federation domain](../mechanics.md).

It does not attach ME networks: an ME cable or device touching a face stays unconnected. Bring networks in with a
<ItemLink id="ae2federation:switch" />.
