# 联邦逻辑处理器

<ItemImage id="ae2federation:federation_logic_processor" scale="4" />

所有联邦设备都要用到的材料。 在<ItemLink id="ae2:inscriber" />中压制： 福鲁伊克斯粉放顶槽， <ItemLink id="ae2:logic_processor" />放中槽， 底槽留空。 两种原料都会被消耗。 粉放在底槽也同样可以压制。

<RecipeFor id="ae2federation:federation_logic_processor" />

它可以像AE2自己的处理器一样自动化： 从一侧给压印器送料， <ItemLink id="ae2:fluix_dust" />会自动进入顶槽， 处理器会自动进入中槽。

用于： <ItemLink id="ae2federation:bridge" />、<ItemLink id="ae2federation:cable" />、<ItemLink id="ae2federation:pattern_provider" />和<ItemLink id="ae2federation:processing_endpoint" />。
