# 安装与触发

函数要装到联邦域里的计算设备上才会运行。 联邦界面的**自动化**标签页左边把每个程序显示为一张卡片， 右边是这个联邦域的计算设备。

## 安装

* 在程序卡片里按住一个函数的那一行并拖动： 一根连线跟着鼠标， 计算设备随之亮起。 松开在某台设备上， 函数就装到了那里。
* 有参数的函数会先逐个询问参数： 物品填ID， 接口或网络填ID或别名， 以及数字。 同一个函数可以用不同参数安装多次。
* 私有函数（`_名字`）不能安装。 被安装的函数调用到的一切都随它一起安装。
* 安装运行的是程序最后一次推送的版本。 设备运行的是当前版本时， 它的方块是绿色； 有修改等待**推送**时是黄色。

## 安装的设置

在设备卡片里点击一个安装。 旁边的面板显示它的参数、设置、是否在运行， 以及日志。 点击参数或数字就能修改。

**触发**： 什么启动一次运行。

| 触发 | 何时启动 |
| --- | --- |
| 手动 | 只在点击**立即运行**时 |
| 红石 | 红石信号到达计算设备时 |
| 定时 | 每隔若干刻 |
| 条件 | 同一程序里一个返回`bool`、且不执行操作的函数变为真时 |
| 事件 | 联邦域里发生某件事时 |

**事件**在输入框里输入， 下方会列出匹配的事件：

* 针对一种资源： `stock_changed`、`crafting_changed`、`craftable_changed`。
* 针对联邦域的网络： `network_boot`、`power_changed`、`controller_changed`、`cpus_changed`、`spatial_io`。
* 针对接口所指的方块（最远4格）： `block_changed`、`crop_grew`、`right_clicked`。

**最小间隔**： 每隔这么多刻最多启动一次运行， 默认20。 间隔内到来的触发合并成间隔结束后的一次运行。

**运行中时**： 上一次运行还没结束时， 新的触发怎么处理。

* **忽略**： 丢弃这次触发。 这是默认值。
* **重启**： 停止当前运行， 开始新的运行。 已经做完的事不会撤销。
* **并行**： 在旁边再开一次运行， 最多同时4次。

**日志**： 最近20条记录， 最新的在最前： 开始、完成及结果、失败及错误和所在行。 `print(...)`会添加一行。 日志只保存在内存里， 服务器重启后为空。

## 运行何时停止

计算设备被拆掉或卸载、或者服务器停止时， 运行会停止。 安装仍然保留， 之后的触发会启动新的运行。 安装发起的合成任务会继续进行， 仍可用`ae2.cancel`取消。

## 命令

管理员也可以用`/ae2federation programs`完成同样的事： `list`、`push`、`devices`、`interfaces`、`install`、`installations`、`uninstall`、`trigger`、`interval`、`overlap`、`run`、`log`和`reload`。
