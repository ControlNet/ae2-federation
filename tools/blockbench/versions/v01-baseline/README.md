# V01 baseline

Frozen snapshot of the pre-redesign Blockbench projects. Device projects are
byte-for-byte copies of `art/blockbench/` at the start of this study. Textures are
extracted from their embedded PNGs. The additional `review_family.bbmodel` uses
the same arrangement as V02, with original V01 textures, for direct comparison.

Renders were captured in Blockbench 5.2.1 through MCP. The individual Provider,
Router and Endpoint images use the same camera as their V02 counterparts.
These are editor renders, not new Minecraft screenshots.
